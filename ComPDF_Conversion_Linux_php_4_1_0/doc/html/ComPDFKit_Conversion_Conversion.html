ComPDFKit\Conversion\Conversion

ComPDFKit\Conversion\Conversion

High-level wrapper around the CPDF_StartPDFTo* functions. Each method returns the raw CSDKErrorCode integer. Use {@see ErrorCode} to interpret the value, or call {@see Conversion::convert()} which throws on error.

Callbacks are not currently exposed; pass NULL to the SDK so all calls run synchronously without progress callbacks (matching the Go binding's default behaviour when no callback is registered).

Source: compdf_sdk/php/samples/src/Conversion.php
